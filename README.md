# Bank telemarketing | Comparing classifiers

[Open the analysis notebook](comparing_classifiers.ipynb)

The bank needs to prioritize calls when agent time is limited. This notebook evaluates logistic regression, K-nearest neighbors, a decision tree and a linear support vector machine. It compares ranking quality and subscriptions per 100 calls against untargeted selection on later campaigns.

## Reproduce the analysis

Install `requirements.txt` with pip and launch JupyterLab from this directory. Extract the course data under this directory or allow the notebook to download the UCI archive. Run all cells and save the notebook with its outputs. The final cell writes the measured findings into this README. Results are pending execution.

[UCI Bank Marketing dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing)
